# Trade Diary Dashboard

Dashboard web para registro, análise e acompanhamento de operações de trading.

O projeto foi desenvolvido para centralizar informações operacionais, métricas de risco, disciplina, contas, importação de trades e análise de performance em uma interface visual.

## Visão geral

O Trade Diary Dashboard é uma aplicação front-end para traders que desejam acompanhar suas operações com mais organização.

A ferramenta permite visualizar métricas, analisar comportamento operacional, acompanhar saldo por conta, importar operações e observar indicadores de risco, disciplina e consistência.

## Problema que resolve

Muitos traders registram operações em planilhas soltas ou anotações manuais, o que dificulta a análise de performance, risco, disciplina e evolução da banca.

Este projeto busca centralizar essas informações em um dashboard visual, facilitando o acompanhamento operacional e a revisão dos resultados.

## Funcionalidades

- Dashboard operacional.
- Registro e análise de trades.
- Filtro por conta.
- Métricas de risco.
- Análise de disciplina.
- Importação de operações.
- Acompanhamento de saldo.
- Visualização de performance.
- Métricas psicológicas e comportamentais.
- Interface web responsiva.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Chart.js via CDN
